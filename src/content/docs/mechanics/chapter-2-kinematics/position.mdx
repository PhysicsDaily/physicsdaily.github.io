## Concept & Definition

To describe how an object moves, the first question we must answer is straightforward: *where is it located?* In mechanics, **position** specifies the location of a particle in space relative to an agreed-upon reference point, known as the **origin** ($O$).

The **position vector**, denoted by $\vec{r}$ (or bold $\mathbf{r}$), is a directed arrow drawn from the origin directly to the point where the particle is situated. Because specifying a location requires both how far away the particle is and in which direction it lies, position is fundamentally a **vector quantity**.

<Callout type="definition" title="Units and Dimensions">
The SI unit of position is the meter ($\text{m}$), and its dimensional formula is $[\text{L}]$.
</Callout>

## Coordinate Systems and Dimensions

Position can be defined across different spatial dimensions depending on the constraints of motion:

- In **one dimension (1D)**, motion is confined to a straight line (such as the $x$-axis). The position is specified by a single signed coordinate $x$, where $\vec{r} = x\hat{i}$.
- In **two dimensions (2D)**, motion occurs in a plane. The position is specified by an ordered pair $(x, y)$, where $\vec{r} = x\hat{i} + y\hat{j}$.

## Mathematical Formulation

In a three-dimensional Cartesian coordinate system with origin $O(0, 0, 0)$, the position vector of any point $P(x, y, z)$ is expressed in terms of the standard unit vectors:

<FormulaCard title="Position Vector in 3D" label="Key Formula">

$$
\vec{r} = x\hat{i} + y\hat{j} + z\hat{k}
$$

where $(x, y, z)$ are the Cartesian coordinates of the particle and $(\hat{i}, \hat{j}, \hat{k})$ are unit vectors pointing along the $x$, $y$, and $z$ axes.

</FormulaCard>

## Magnitude and Distance

The magnitude of the position vector represents the straight-line distance from the origin $O$ to the particle at point $P$. By applying the three-dimensional Pythagorean theorem, this distance is:

<FormulaCard title="Magnitude from Origin" label="Distance">

$$
r = |\vec{r}| = \sqrt{\rule{0pt}{2.7ex}x^2 + y^2 + z^2}
$$

where $r = |\vec{r}|$ is the scalar distance from the origin $(0, 0, 0)$ to the particle at $(x, y, z)$.

</FormulaCard>

## Relative Position and Reference Frames

Position has no absolute meaning on its own—it is always defined relative to a chosen frame of reference. If the observer is not at the origin $(0, 0, 0)$ but located at coordinates $\vec{r}_0 = (x_0, y_0, z_0)$, the position vector of the particle relative to the observer is given by:

<FormulaCard title="Relative Magnitude" label="Relative Position">

$$
|\vec{r} - \vec{r}_0| = \sqrt{\rule{0pt}{2.7ex}(x - x_0)^2 + (y - y_0)^2 + (z - z_0)^2}
$$

where $(x, y, z)$ are the coordinates of the particle and $(x_0, y_0, z_0)$ are the coordinates of the observer.

</FormulaCard>

<Callout type="warning" title="Reference Frame Dependency">
Position is not an intrinsic property of a particle. Changing the origin or rotating the coordinate axes changes the coordinate values and the position vector $\vec{r}$, even if the physical object remains completely stationary relative to the surroundings.
</Callout>
